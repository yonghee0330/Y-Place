# 역곡동 용서점

2018년 문을 연 동네책방의 작은 가상 공간. `npm ci`, `npm run dev`로 실행한다.

## 남은 이슈 / 가정한 것

- 실제 사진의 합판, 크림색 벽, 책이 빽빽한 서가, 따뜻한 전등갓을 참고한다. 크기와 정확한 배치는 실측이 아닌 가정이다.
- 서점 5.5×4.5m / 8명, 모임방 4.2×4.2m / 6명(좌석 5).
- 간판: 역곡동 용서점 · 큐레이팅 동네책방 · 2018.
- 고양이와 연출용 NPC는 없음. 방명록과 읽는 책은 로컬 중심. Supabase 계정과 키는 원본에서 복사하지 않음.
- 운영자 코드는 VITE_MANAGER_CODE로 설정하며 기본값은 없음. 정적 사이트의 외형 전환용이고 보안 인증 기능은 아님.
- 지정 BGM·도메인이 없어 외부 음악과 커스텀 도메인은 연결하지 않음.
- 새 패키지를 추가하지 않음. 원본 이력과 운영자 사진은 로컬 docs에 보존하며 Git에서 제외.
