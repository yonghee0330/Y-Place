## 4단계
- 04-shop / 04-counter / 04-circle 직접 열어 확인: 밀도 있는 책장, 베벨 원탁·5석, 합판 간판, 주름 전등갓, 동심원 패브릭, 계산대와 벤치.
- 03-shop-seats와 실제 클릭 로그로 서점 5석 착석 확인. 두 방 접근점·모든 좌석 간 경로도 통과.
- 04-mobile-start / 04-mobile-shop / 04-mobile-reading: 420px 화면에서 입장 버튼·액션 버튼·책 카드·소리 켜짐 확인. 벽 앞에서 아바타 머리가 화면을 덮던 구도를 수정함.
- 04-mobile-keyboard-sheet: visualViewport 높이 460px 시 시트가 그 안으로 이동함. 마지막 촬영은 시트 등장 애니메이션 중이므로 최종 검사에서 애니메이션 완료 상태로 다시 촬영할 것.
- SwiftShader 정적 캡처 콘솔 오류 0. 모바일 e2e pageerror/console error 0. 실제 iOS와 하드웨어 청음은 미검증.

## 5단계 — 최종 검증
- 05-mobile-start / shop / keyboard-sheet / reading을 직접 열어 확인. 등장 애니메이션을 완료시킨 캡처에서 시트는 축소된 460px 영역 안에 있고 제목 입력·검색·취소·확인 버튼이 잘리지 않음. 상단 날씨는 좁은 화면에서 숨겨 겹침 해소.
- 05-circle-seated / 05-shop-seats 직접 확인. 원탁 5석과 서점 5석 실제 마우스 클릭으로 이동·착석. 원탁 시선은 테이블 중심과 내적 > .99.
- 최종 e2e 5개 전부 통과(58초): 문 왕복 2회, 모바일 독서·AudioContext running, 만석 복귀, 모임방 5석, 서점 5석. 캡처 및 검사에서 수집한 콘솔 오류 0.
- 04-shop/counter/circle은 동일한 최종 3D 모델의 SwiftShader 캡처. 5단계에서는 검증 스크립트와 문서만 변경.
- 실제 휴대폰의 키보드·청음·프레임률은 확인하지 못함. 제공 사진을 그대로 재현한 실측 공간이 아닌 절차 모델의 가상 배치임.

## 7 — 슬림 미니미 아바타 (2026-11-10)
- 07-avatar-front: 키 약 1.1m, 약 3.5등신. 큰 머리, 좁은 어깨·가는 팔다리, 팔꿈치·무릎 관절. 어깨 관절이 몸통 안쪽으로 들어가 튀어나오지 않음. 비북스-M의 종 모양 몸통과 다른 실루엣.
- 07-avatar-manager: 운영자 안경·콧수염·턱수염·목수 앞치마가 새 몸통에 맞게 붙음. 턱수염이 턱 아래로 삐져나오지 않음.
- 07-avatar-drink: 잔이 오른손에 붙어 똑바로 서 있음. 07-avatar-walk: 앞으로 나가는 다리의 무릎이 굽음.
- 07-avatar-circle-read / circle-side: 모임방 의자에 앉아 무릎이 접히고 발이 의자 앞에 매달림. 양손으로 책을 가슴 앞에 듦. 이름표가 머리 위에 붙음.
- 07-avatar-follow-sit: 기본 따라가기 시점에서 창가 안락의자에 앉은 모습.
- 콘솔 오류 0. e2e 5/5(58초), 좌석 경로·정원 검사 통과. 05-* 캡처도 새 아바타로 갱신됨.
- 입장 직후 내 아바타가 숨겨지던 문제는 8에서 해결.

## 8 — 입장 직후 내 아바타 보이기 (2026-11-10)
- 원인: 입장 자리가 뒷벽에서 0.6~0.65m라 따라가기 카메라가 머리 바로 뒤에 붙고, 1인칭 처리로 내 아바타가 숨겨짐(공개 사이트에서도 재현).
- 서점 입장 자리 z 1.6→1.05, 모임방 두 입장 자리 z 1.45/1.5→0.95로 옮김(의자·매대와 0.5m 이상 간격).
- 08-entry-desktop-shop / desktop-circle / mobile-shop / mobile-circle: 네 화면 모두 `meVisible() === true`, 아바타와 이름표가 보임. 콘솔 오류 0.
- 좌석 경로·정원 검사, e2e 5/5(57초) 통과.

## 9 — 라운지 재구성 + 작업실 4개 (2026-11-14)
- 09-lounge: 창가 안마 의자 2개와 러그·협탁·스탠드, 가운데 소파와 낮은 테이블, 왼쪽 서가·카페 테이블. 2D처럼 보이는 평면 없음, 가구마다 베벨·두께·그림자.
- 09-lounge-massage / massage-seated: 안마 의자는 받침·몸통·팔걸이 홈·등 쿠션 3단·머리 베개·어깨 날개·종아리 홈·발 받침·리모컨으로 구성. 아바타가 좌석에 앉고 팔걸이·등받이와 겹치지 않음. (1차: 머리 위 덮개가 떠 보여 낮춤)
- 09-lounge-coffee: 문짝 3개 수납장, 타일 뒷벽, 에스프레소 머신(추출부 2·포터필터·압력계·컵 난간), 그라인더, 드립 주전자, 드리퍼, 머그 쟁반, 벽 선반, 메뉴판. (1차: 그림이 선반과 겹쳐 옮김, 테이블 위 어색한 그릇 제거)
- 09-lounge-doors: 작업실 문 4개와 간판. (1차: 간판이 한 줄로 붙어 겹침 → 문마다 폭 0.84m 간판으로 분리)
- 09-work1~4, work4-desk: 책상 색·소품·메모 배치·화분/스탠드 위치가 방마다 다름. (1차: 노트북 화면이 하얗게 번짐·메모판이 주황색 → 밝기·색 조정)
- 10-entry-*: 라운지·작업실 입장 직후 데스크톱·모바일 모두 `meVisible() === true`. (1차: 데스크톱 라운지에서 아바타 숨겨짐 → 입장 자리·소파 위치 조정)
- 판정: 통과. 콘솔 오류 0, e2e 6/6.

## 11 — 개인 작업실 문 + 집중 기능 (2026-11-14)
- 11-door: 라운지 오른쪽 벽에 문 하나, 간판 "개인 작업실". 문 양옆 화분·그림으로 빈 벽을 채움.
- 11-desk-morning/day/sunset/night: 내 자리 시점. 탁상시계에 남은 시간과 진행 링, 스탠드가 노트·노트북을 비추고 빛 속 먼지가 보임. 창 없는 방이라 시간대 차이는 작음(밤에 방 전체 빛만 줄어듦).
- 11-desk-focusmode: HUD·이름표가 사라지고 타이머만 아래 가운데에 얇게 남음.
- 11-lounge-sunset/night: 창밖 하늘·지붕이 해질녘엔 주황, 밤엔 어둡게. 실내는 스탠드·펜던트 빛이 주인공.
- 11-mobile-desk: 390px. 정면 위 시점에서 책상·'집중 중' 팻말·시계가 보이고, 패널은 아래 버튼 위에 놓여 알림과 겹치지 않음.
- 1차에서 고친 것: 모바일 내 자리 시점 카메라가 서가에 박혀 화면이 뭉개짐 → 정면 위 시점. 패널이 위쪽 알림과 겹침 → 데스크톱 오른쪽 위·모바일 아래로. 내 이름표가 책상을 가림 → 내 자리 시점에서 숨김. 밤 창밖이 낮과 같음 → 하늘·지붕 색 낮춤.
- 판정: 통과. 콘솔 오류 0, e2e 8/8.
