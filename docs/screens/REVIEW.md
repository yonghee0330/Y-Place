# 화면 검토

## 1단계
- 01-shop.png / 01-circle.png 직접 열어 확인: 판재 바닥, 몰딩, 문, 방 이름과 정원.
- 첫 캡처의 모임방 카메라가 벽 밖에 있었음. 내부 좌표(1.8, 2.25, 1.8)로 재촬영.
- Playwright 콘솔 오류 0. 아직 빈 방 단계이므로 가구 품질 판정은 다음 단계.

## 2단계
- 02-circle.png: 5개 의자가 원탁 중심을 향함, 상판의 둥근 가장자리와 다리, 잔·화병 확인.
- 02-circle-seated.png: 마지막 좌석에 앉은 아바타 확인. e2e 5석 전부 클릭 착석 통과.
- 합판과 벽의 명도·나뭇결 대비는 사진과 비교하여 다음 단계에서 조정.

## 3단계
- 03-shop.png: 창가 2석·사이드 테이블, 양쪽 서가, 합판 매대와 철제 다리, 주름 램프 확인.
- 03-counter.png: 계산대·스툴·2인 벤치·합판 간판·동심원 패브릭 확인.
- 03-circle.png: 공통 색조를 밝은 합판·크림벽·차분한 패브릭으로 변경.
- 첫 구도에서 가까운 펜던트가 화면 상단을 크게 가림. 촬영 좌표를 중앙으로 옮겨 재촬영.
- 실제 사진과 동일한 실측 복원이라고 주장하지 않음. 가상 배치 가정은 README와 로컬 reference/README에 기록.

## 4단계
- 04-shop / 04-counter / 04-circle 직접 열어 확인: 밀도 있는 책장, 베벨 원탁·5석, 합판 간판, 주름 전등갓, 동심원 패브릭, 계산대와 벤치.
- 03-shop-seats와 실제 클릭 로그로 서점 5석 착석 확인. 두 방 접근점·모든 좌석 간 경로도 통과.
- 04-mobile-start / 04-mobile-shop / 04-mobile-reading: 420px 화면에서 입장 버튼·액션 버튼·책 카드·소리 켜짐 확인. 벽 앞에서 아바타 머리가 화면을 덮던 구도를 수정함.
- 04-mobile-keyboard-sheet: visualViewport 높이 460px 시 시트가 그 안으로 이동함. 마지막 촬영은 시트 등장 애니메이션 중이므로 최종 검사에서 애니메이션 완료 상태로 다시 촬영할 것.
- SwiftShader 정적 캡처 콘솔 오류 0. 모바일 e2e pageerror/console error 0. 실제 iOS와 하드웨어 청음은 미검증.
