## 제안 (2026-11-17)

형식: 무엇 / 왜 / 무료 한도 / 작업량 / 위험 / 되돌리기 / 검증 지표.
"MCP"는 사이트가 실행 중에 쓰는 연결이 아니라, Claude Code가 작업할 때 쓰는 연결이다. 그래서 MCP 아이디어는 "콘텐츠를 자동으로 갱신해 배포"하는 쪽으로 쓴다.

### A. Claude만으로 (NPC 대화 Worker 재사용)

1. **NPC가 지금 공간을 안다** — 상태: 완료 (2026-11-22)
   - 무엇: 현재 접속자 수, 사람들이 읽는 책 제목, 시간대·날씨, 내가 앉은 자리를 대화에 함께 보낸다.
   - 왜: "지금 몇 명 있어요?", "저 사람 뭐 읽어요?"에 답하게 된다. 살아 있는 공간 느낌이 난다.
   - 무료 한도: 추가 서비스 없음. 토큰이 조금 늘어난다.
   - 작업량: 작음(반나절).
   - 위험: 닉네임 외의 정보는 보내지 않아야 한다.
   - 되돌리기: 맥락 필드를 빼면 된다.
   - 지표: 답 정확도를 수동으로 10문항 점검한다.
   - 구현: `NpcSceneContext`를 `/chat`에 선택 필드로 보냄. Worker는 캐시된 성격 뒤에 [지금 이 순간] 블록만 붙임. AI 없거나 실패 시 로컬 안내 답도 같은 맥락 사용. 검사 `scripts/check-npc-context.mjs`.
2. **책 큐레이터 / 주간 신간 제안** — 상태: 완료 (2026-11-22)
   - 무엇: 주간 매체 추천 신간 목록을 바탕으로 NPC가 2~3권을 고르고, 서가 앞 받침대·「신간」 시트로 보여 준다. (카카오 검색 표지 연동은 다음 단계)
   - 왜: 책방·서재 정체성에 맞고, 비북스-M에 옮길 1순위다.
   - 무료 한도: 추가 서비스 없음(목록은 저장소 데이터).
   - 작업량: 중간.
   - 위험: 목록에 없는 책을 지어내는 것 → NPC·로컬 답은 목록 안만 사용.
   - 되돌리기: 신간 데이터·받침대·시트·HUD 버튼 제거.
   - 지표: 시트에서 고른 책이 읽기 상태로 반영, 큐레이터 추천 답이 목록 제목을 포함.
   - 구현: `src/reader/newReleases.ts`(2026-W47), 서재·책방 받침대, HUD「신간」, 큐레이터/로컬·Worker 맥락.
3. **작업실 작업 코치** — 상태: 제안
   - 무엇: 타이머를 시작할 때 "오늘 할 일"을 말하면 25분 단위로 쪼개 메모판에 붙인다. 끝나면 회고를 한 줄로 요약한다.
   - 왜: 1인 작업실의 핵심 경험을 강화한다.
   - 무료 한도: Claude 토큰만 든다.
   - 작업량: 중간.
   - 위험: 작업 내용이 서버로 간다. 보내기 전에 안내하고 선택제로 한다.
   - 되돌리기: 끄기.
   - 지표: 세션 완료율(로컬 기록).
4. **모임방 토론 질문 보드** — 상태: 제안

   - 왜: 비북스 독서 모임 진행에 바로 쓸 수 있다.
   - 무료 한도: Claude 토큰.
   - 작업량: 작음~중간.
   - 위험: 책 내용을 지어낼 수 있다. 제목·소개 기반의 일반 질문으로 제한한다.
   - 되돌리기: 끄기.
   - 지표: 운영자 만족도.
5. **NPC 말풍선** — 상태: 제안
