## 제안 (2026-11-17)

형식: 무엇 / 왜 / 무료 한도 / 작업량 / 위험 / 되돌리기 / 검증 지표.
"MCP"는 사이트가 실행 중에 쓰는 연결이 아니라, Claude Code가 작업할 때 쓰는 연결이다. 그래서 MCP 아이디어는 "콘텐츠를 자동으로 갱신해 배포"하는 쪽으로 쓴다.

### A. Claude만으로 (NPC 대화 Worker 재사용)

1. **NPC가 지금 공간을 안다** — 상태: 제안
   - 무엇: 현재 접속자 수, 사람들이 읽는 책 제목, 시간대·날씨, 내가 앉은 자리를 대화에 함께 보낸다.
   - 왜: "지금 몇 명 있어요?", "저 사람 뭐 읽어요?"에 답하게 된다. 살아 있는 공간 느낌이 난다.
   - 무료 한도: 추가 서비스 없음. 토큰이 조금 늘어난다.
   - 작업량: 작음(반나절).
   - 위험: 닉네임 외의 정보는 보내지 않아야 한다.
   - 되돌리기: 맥락 필드를 빼면 된다.
   - 지표: 답 정확도를 수동으로 10문항 점검한다.
2. **책 큐레이터** — 상태: 제안
   - 무엇: 기분이나 상황을 말하면 NPC가 책 2~3권을 추천한다. 카카오 책 검색(이미 `kakaoApi.ts` 있음)으로 실존 여부와 표지를 확인한다. 추천 책은 서가 앞 "오늘의 추천" 받침대에 3D 책으로 놓인다.
   - 왜: 책방에 가장 잘 맞고, 비북스-M에 옮길 1순위다.
   - 무료 한도: 카카오 API 일일 한도(미확인).
   - 작업량: 중간(Claude 도구 사용 + 3D 받침대).
   - 위험: 없는 책을 추천하는 것. 검색으로 확인된 책만 보여 준다.
   - 되돌리기: 기능 끄기.
   - 지표: 추천 책 검색 일치율.
3. **작업실 작업 코치** — 상태: 제안
   - 무엇: 타이머를 시작할 때 "오늘 할 일"을 말하면 25분 단위로 쪼개 메모판에 붙인다. 끝나면 회고를 한 줄로 요약한다.
   - 왜: 1인 작업실의 핵심 경험을 강화한다.
   - 무료 한도: Claude 토큰만 든다.
   - 작업량: 중간.
   - 위험: 작업 내용이 서버로 간다. 보내기 전에 안내하고 선택제로 한다.
   - 되돌리기: 끄기.
   - 지표: 세션 완료율(로컬 기록).
4. **모임방 토론 질문 보드** — 상태: 제안
   - 무엇: 모임지기에게 책 제목을 주면 토론 질문 5개를 만들어 벽 보드(3D)에 띄운다.
   - 왜: 비북스 독서 모임 진행에 바로 쓸 수 있다.
   - 무료 한도: Claude 토큰.
   - 작업량: 작음~중간.
   - 위험: 책 내용을 지어낼 수 있다. 제목·소개 기반의 일반 질문으로 제한한다.
   - 되돌리기: 끄기.
   - 지표: 운영자 만족도.
5. **NPC 말풍선** — 상태: 제안
   - 무엇: 대화 창 밖에서도 NPC 머리 위에 답의 첫 문장을 몇 초 띄운다.
   - 왜: 3D 공간 안에서 대화가 보인다.
   - 무료 한도: 없음.
   - 작업량: 작음.
   - 위험: 다른 방문자에게는 보이지 않게(로컬 전용) 한다.
   - 되돌리기: 끄기.
   - 지표: 캡처 확인.

### B. 브라우저 내장 기능 (무료, 외부 서비스 없음)

6. **음성으로 NPC와 대화** — 상태: 제안
   - 무엇: 마이크 버튼으로 말하면 글자로 바꾸고(Web Speech API), NPC 답을 음성으로 읽는다(speechSynthesis).
   - 왜: 모바일에서 타자가 필요 없다.
   - 무료 한도: 브라우저 기능이라 무료. 다만 Chrome 음성 인식은 구글 서버를 쓸 수 있다(개인정보 안내 필요).
   - 작업량: 작음.
   - 위험: 브라우저마다 지원이 다르다. 지원하지 않으면 버튼을 숨긴다.
   - 되돌리기: 끄기.
   - 지표: 지원 브라우저 동작 확인.
